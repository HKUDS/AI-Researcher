\section{Methodology}
\label{sec:methodology}

The primary methodological contribution is three evaluation controls that isolate genuine detection signal from artifacts. The ADAGE adaptive interrogation pipeline serves as the measurement apparatus through which these controls are applied.

\subsection{Evaluation Controls}
\label{sec:eval_controls}

We apply three controls that any behavioral deception detection system should adopt:

\paragraph{Prompt equalization.} Standard instructed-deception evaluations use asymmetric system prompts (``answer honestly'' vs.\ ``the claim is FALSE, defend it by lying''). Our \emph{prompt-equalized control} gives both conditions identical neutral prompts (``You are a helpful assistant. Share what you know about this topic.'') and varies only claim truthfulness. Any behavioral difference arises from knowledge conflict, not instruction asymmetry.

\paragraph{Cross-family feature extraction.} When the feature extractor belongs to the same model family as the target, self-preference bias may inflate discriminative scores. Our \emph{cross-family extraction control} re-extracts features using extractors from a different model family, separating genuine signal from same-family artifacts.

\paragraph{Surface-level baselines.} LLM-extracted behavioral features may capture surface lexical patterns rather than latent behavioral properties. Our \emph{hedging-word regex baseline} extracts seven text-level features via pattern matching (no LLM calls), bounding the contribution of LLM-extracted features from above.

\subsection{Measurement Apparatus: ADAGE Pipeline}
\label{sec:system_overview}

The ADAGE pipeline takes as input a claim and a target model; the target is conditioned on a system prompt (asymmetric under instructed roleplay, identical across conditions under equalization) and an opening user turn stating the claim. An \emph{interrogator} LLM generates follow-up questions conditioned on the dialogue history, producing up to 8 question/response pairs per trial. A \emph{feature extractor} LLM scores each response on 5 behavioral dimensions on a 0--10 scale: \textbf{consistency} (alignment with earlier responses), \textbf{specificity} (concrete detail vs.\ vagueness), \textbf{correction-marker density} (frequency of refusals, hedges, and factual corrections), \textbf{confidence} (certainty language), and \textbf{elaboration} (unprompted extension). Trial-level feature means feed a logistic regression classifier, and an adaptive stopping mechanism halts interrogation when classifier confidence exceeds 0.80 (max 8 questions). The output is a binary label (truth/lie) plus a confidence score. The correction-marker density feature has weak construct validity (Section~\ref{sec:icc_owned}), motivating the regex baseline control: a single refusal-count heuristic matches or exceeds the full LLM pipeline on 6 of 7 models under equalization (Section~\ref{sec:hedging_baseline}). Target model configurations are in Appendix~\ref{app:target_config}. The pipeline is the experimental vehicle, not the contribution.
