\begin{abstract}
Detecting deceptive behavior in large language models (LLMs) is an emerging challenge as these systems are deployed in high-stakes settings. This paper introduces ADAGE, an adaptive interrogation framework for \emph{behavioral deception detection in constrained roleplay settings}, where an investigator LLM poses strategically sequenced questions to classify whether a target LLM is truthfully or deceptively answering questions about a claimed identity. The framework combines information-theoretic question selection with a Bayesian early-stopping mechanism and a logistic regression classifier operating over behavioral feature vectors extracted from interrogation transcripts. In a controlled mock study ($n=100$ trials), the adaptive method achieves 93\% classification accuracy while requiring 75\% fewer questions than a fixed 8-question baseline that attains 100\% accuracy, revealing an explicit accuracy--efficiency tradeoff; 5-fold cross-validation yields 100\% $\pm$ 0\% accuracy, confirming the classifier generalizes within the mock distribution. A preliminary pilot on Claude Haiku 4.5 ($n=9$ completed trials) yields 88.9\% overall accuracy but only 50\% lying detection accuracy, exposing a substantial gap between mock and real LLM behavioral patterns. Notably, the single misclassified deceptive trial exhibited high classifier confidence (0.92), confirming a calibration limitation. We present ADAGE as a proof-of-concept demonstrating the feasibility of structured behavioral interrogation for LLM deception detection, while emphasizing that validation at scale with diverse models and richer deception scenarios remains essential before practical deployment.
\end{abstract}
