\begin{abstract}
Can black-box behavioral probing detect when a language model is lying? We investigate this question through ADAGE, an adaptive interrogation framework that poses strategically sequenced questions, extracts five behavioral features per response, and classifies truth-telling vs.\ lie-defending via logistic regression. Our central finding is negative: removing instruction asymmetry via a prompt-equalized control drops detection accuracy from 93.9--100\% to 64--71\% across Mistral~7B and Llama~3.2~3B, with all five features collapsing. The pipeline primarily detects how models comply with different instructions, not deception per se. Three confounds explain the instructed-condition accuracy. RLHF safety refusals drive Claude Haiku's 97.8\% LOO; same-family extractor inflation reduces cross-family defensiveness $d$ from $+4.90$ to $+0.63$; and a hedging-word regex baseline matches or exceeds the full LLM pipeline on the equalized condition (73--78\% vs.\ 64--71\%). Held-out evaluation and permutation tests confirm these results are not overfitting artifacts. We offer this work as an empirical characterization of where instructed lie detection succeeds, where it fails, and what confounds the signal.
\end{abstract}
